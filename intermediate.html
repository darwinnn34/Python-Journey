LESSON 1

Functions: reusable building blocks

Use parameters to pass information in and return to send a result back.

def calculate_total(price, quantity):
    return price * quantity

bill = calculate_total(12.5, 3)
print(bill)  # 37.5

A function should have a clear name and ideally do one focused job.

LESSON 2

Collections: keep related values together

Lists are ordered and editable. Dictionaries connect keys to values.

tools = ["Python", "pandas", "SQL"]
tools.append("Matplotlib")
print(tools[0])  # Python

person = {"name": "Darwin", "role": "Data Analyst"}
print(person["role"])

List positions start at zero. Use a dictionary when each value has a meaningful label.

LESSON 3

Files: save and load information

The with statement closes a file safely when you finish.

with open("notes.txt", "w", encoding="utf-8") as file:
    file.write("Keep practicing Python!\n")

with open("notes.txt", encoding="utf-8") as file:
    notes = file.read()
    print(notes)

Use "w" to write (replaces old contents), "a" to append, and "r" to read.

LESSON 4

Exceptions: handle things that can go wrong

try:
    age = int(input("Your age: "))
except ValueError:
    print("Please enter a whole number.")

Handle errors you expect, and give people a useful next step.
