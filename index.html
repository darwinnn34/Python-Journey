Start here: your first steps

Set up Python, learn the building blocks, then practice by changing the examples yourself.

1. Install Python

  1. Go to python.org/downloads.
  2. Download the latest stable version for your computer.
  3. On Windows, run the installer and tick “Add Python to PATH”, then choose Install Now.
  4. Open Terminal (Mac) or Command Prompt / PowerShell (Windows) and type python --version. If that doesn’t work on Windows, try py --version.
  5. Choose an editor such as VS Code, create hello.py, and run it with python hello.py (or py hello.py).

What just happened?

Python is the language interpreter that runs your instructions. A .py file is a plain text file containing Python code. The terminal is where you ask Python to run that file.

# hello.py
print("Hello, world!")

Save the file, run it, and you should see Hello, world!.

LESSON 01

Print: show something on screen

Use print() to display text, numbers, or the result of an expression.

print("Hello, Darwin!")
print(2 + 3)
# Output: Hello, Darwin! then 5

Text goes inside quotes. Numbers and calculations can go directly inside the parentheses.

LESSON 02

Variables: give information a name

A variable stores a value so you can reuse or change it.

name = "Darwin"
age = 25
print(name)
print(age + 1) # 26

The equals sign assigns a value. Pick clear names such as first_name or total_score.

LESSON 03

Data types: different kinds of values

Python values have types, and each type is suited to different work.

name = "Darwin" # str: text
age = 25 # int: whole number
score = 98.5 # float: decimal number
is_learning = True # bool: True or False
skills = ["Python", "SQL"] # list: collection

Check a value’s type with type(age). Convert input when needed: age = int(input("Age? ")).

LESSON 04

Conditions and loops

Make decisions with if and repeat work with for.

score = 82
if score >= 60:
    print("Pass")

for tool in ["Python", "pandas", "SQL"]:
    print(tool)

Indentation matters in Python: the indented lines belong to the condition or loop above them.

LESSON 05

Functions: reusable instructions

A function bundles steps under a name. Give it input and it can return a result.

def greet(person):
    return f"Hello, {person}!"

message = greet("Darwin")
print(message)

Practice: change the greeting, make a function that doubles a number, and explain each line in your own words.
