LESSON 1

SQL: ask questions of a table

Imagine a table called sales with columns product, region, and amount.

SELECT region, SUM(amount) AS revenue
FROM sales
WHERE amount > 0
GROUP BY region
ORDER BY revenue DESC;

SELECT chooses columns, WHERE filters rows, GROUP BY summarizes categories, and ORDER BY sorts results.

LESSON 2

pandas: work with tables in Python

pandas stores rows and columns in a DataFrame, which is handy for analysis.

import pandas as pd

sales = pd.DataFrame({
    "product": ["Book", "Pen", "Book"],
    "amount": [12, 3, 15]
})
print(sales["amount"].sum())  # 30
print(sales.groupby("product")["amount"].sum())

Try reading a CSV with pd.read_csv("sales.csv"), then inspect it with sales.head().

LESSON 4

Charts: make patterns visible

import matplotlib.pyplot as plt

sales.groupby("product")["amount"].sum().plot(kind="bar")
plt.title("Revenue by product")
plt.ylabel("Revenue")
plt.tight_layout()
plt.show()
